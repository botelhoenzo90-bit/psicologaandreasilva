# Imagens do site da Andréa Silva

Coloque os dois arquivos de imagem nesta pasta (**public/images/**):

- `andrea-logo.png` — logomarca da psicóloga. O site procura esse arquivo no topo da página.
- `andrea-silva.jpg` — foto/retrato da Andréa. O site procura esse arquivo na seção “Prazer, sou Andréa”.

## Como adicionar pelo GitHub
1. Abra a pasta `public/images` no repositório.
2. Clique em **Add file → Upload files**.
3. Envie as imagens com exatamente os nomes acima (ou renomeie antes de enviar).
4. Clique em **Commit changes**.

Se os arquivos ainda não estiverem na pasta, o site mantém o espaço reservado e o texto de identificação no lugar da foto. Para a logo, prefira PNG com fundo transparente; para a foto, use JPG ou WebP de boa qualidade.
